## 2026-04-28 · Drawer + DataTable primitive a11y fixes (cross-cutting) · /generalworks testid wiring

Two real a11y bugs surfaced + fixed via interactive inspection of `/generalworks` and the W22 pre-push axe gate. Both are primitive-level fixes that ripple to every adopter.

- **Fix 1 — `Drawer.tsx`** ([src/components/primitives/overlays/Drawer.tsx](../../../src/components/primitives/overlays/Drawer.tsx)): `DrawerHeader` rendered title/subtitle as raw `<div>`s. vaul (Radix Dialog under the hood) requires `Drawer.Title` for screen readers — fired *"DialogContent requires a DialogTitle"* warning every time any detail drawer opened. Wrapped title in `VaulDrawer.Title` + subtitle in `VaulDrawer.Description`. Same visual; correct a11y. Affects every `<DetailDrawer>` adopter (generalworks · whatsapp panel · others).
- **Fix 2 — `DataTable.tsx`** ([src/components/primitives/ui/DataTable.tsx](../../../src/components/primitives/ui/DataTable.tsx)): the wrapping `<div role="table">` contained two `hidden md:block` rowgroups + a `role="list"` mobile body. On mobile-safari (390px) the rowgroups are display:none, so axe sees the role=table with no row/rowgroup visible children → critical `aria-required-children` violation. Surfaced in WF-0310 axe scan, ripples to every LIST adopter. Restructured: `role="table"` only wraps the desktop subtree (with `hidden md:block` on the wrapper itself); mobile `role="list"` is now a sibling. Below md the role=table is fully display:none, axe skips it.
- **/generalworks testid wiring** ([src/features/generalworks/pages/GeneralWorks.tsx](../../../src/features/generalworks/pages/GeneralWorks.tsx)): added `searchTestId="generalworks-search-input"` + `tableTestId="generalworks-table"` props on `<ListPageFrame>`. Repairs pre-existing `WF-0301 search-filter.spec.ts` which targeted the testid; matches the wiring pattern of all other LIST adopters.
- **Verification**: WF-0310 chromium-desktop + mobile-safari both green; WF-0301 chromium-desktop green (8s); full W22 pre-push @p0 suite — 35 passed / 3 skipped (9.9 min). Pushed as `e9aecda7`.
