## Policy design

Compensation = **admin-only by default**, with worker-self carve-outs:
- `is_admin()` — full RCUD everywhere
- `is_finance_role()` — full RCUD on finance tables
- Worker-self: `auth.uid() IN (SELECT auth_user_id FROM public.people WHERE id = row.person_id)` → SELECT own rows only

## Migration SQL draft

```sql
BEGIN;

-- salary
DROP POLICY IF EXISTS "<permissive>" ON public.salary;
CREATE POLICY "salary_select_self_or_finance"
  ON public.salary FOR SELECT TO authenticated
  USING (
    is_finance_role() OR is_admin()
    OR person_id IN (SELECT id FROM public.people WHERE auth_user_id = auth.uid())
  );
CREATE POLICY "salary_write_finance_only"
  ON public.salary FOR INSERT TO authenticated WITH CHECK (is_finance_role() OR is_admin());
CREATE POLICY "salary_update_finance_only"
  ON public.salary FOR UPDATE TO authenticated
  USING (is_finance_role() OR is_admin())
  WITH CHECK (is_finance_role() OR is_admin());
CREATE POLICY "salary_delete_admin_only"
  ON public.salary FOR DELETE TO authenticated USING (is_admin());

-- pay_slips, monthly_payroll_workers, worker_ot, worker_leave_balance, worker_applications — same pattern

COMMIT;
```
