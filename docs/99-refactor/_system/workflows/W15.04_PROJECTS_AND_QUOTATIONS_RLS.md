## Policy design

- Read: `is_approved_user()` (entire team needs project visibility)
- Write: `can_manage_projects()` / `can_manage_quotations()` — capability-based per table type
- Delete: `is_admin()` only (cascades)

## Migration SQL draft

```sql
BEGIN;

-- projects (the permissive SELECT fix)
DROP POLICY IF EXISTS "ai_ro_select" ON public.projects;
CREATE POLICY "projects_select_approved"
  ON public.projects FOR SELECT TO authenticated USING (is_approved_user());
CREATE POLICY "projects_write_pm"
  ON public.projects FOR INSERT TO authenticated WITH CHECK (can_manage_projects());
-- UPDATE, DELETE, plus every project_* subtable — capability-gated accordingly

-- quotations
-- same capability pattern with can_manage_quotations()

COMMIT;
```
