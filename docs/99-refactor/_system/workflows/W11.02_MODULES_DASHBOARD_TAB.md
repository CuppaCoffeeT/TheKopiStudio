## Why this exists

User asked: "I want to see a list of all the modules, and for each module what workflows we have + components used." Right now `/refactor-dashboard` has stage/backlog/decisions tabs but no module-centric view. Without this, progress is flat — you can't see "Quotation has 3/5 P0 workflows green, Payroll has 0/4" at a glance.

This tab becomes the primary UX for Phase 6 batch review: 50 modules × ~3 drafts per module needs batch-able visual review, not chat scrolling.

## Scope

**In:**
- New "Modules" tab on `/refactor-dashboard`
- **Data sources**:
  - `public.modules` via Supabase query (51 rows, live) — authoritative module list
  - `_system/ledgers/WORKFLOW_LEDGER.md` via Vite HMR (same pattern as other tabs)
  - `_system/research/COMPONENT_MAP.md` (from W02) — per-module component derivation
- **UI layout**:
  - Left nav: 51 modules grouped by `category` (9 categories)
  - Detail pane per module:
    - Name, URL path, active/inactive
    - Category chip
    - Workflows table — matched by ledger's `Module` column equal to module path
    - Per workflow: tier, UI/DB/NAS/Gmail/Desktop pills, spec link, last run
    - Components used (optional Phase 4.5 — derive from COMPONENT_MAP.md grep)
    - Compliance pills (fed by W05 drift detector — timezoneUtils, react-query factory, module-based access)
- **"+ describe missing workflow" modal**:
  - User types walkthrough in textarea
  - "Copy to clipboard" button (template: `capture workflow for <module>: <steps>`)
  - User pastes into chat → I create ledger row + spec next session
  - **Zero backend write** — markdown stays canonical

**Out:**
- Write-back to DB (markdown is canonical — clipboard handoff avoids dual source of truth)
- Per-workflow inline editing (edit the .md file directly)
- Visual regression overlay (separate pass)
- Real-time CI status (Phase 8 adds polling from GH Actions API — deferred)

## Implementation notes

- Reuse existing `useRefactorMarkdown.ts` hook pattern — add `parseLedger()` returning typed rows
- New hook `useModulesList()` — Supabase query, React Query cached
- URL matching: ledger `Module` column contains module path (e.g., `/quotations`) → exact match against `modules.path`
- Module without any workflows: show card with "No workflows captured yet — describe one?" CTA
- Module with workflows: show summary pills (e.g., `3/5 green · P0 2/2 green`)
- Category-level rollup at top of each category group
