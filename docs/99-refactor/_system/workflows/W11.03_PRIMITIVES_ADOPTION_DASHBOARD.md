# W11.03 — Primitives adoption dashboard tab

**Goal**: A live, cross-linked view of every primitive's lifecycle stage (Designed → Built → Adopted) at `/refactor-dashboard` → new **Primitives** tab. Replaces the hand-maintained DESIGN_CATALOG.md Adopted column with live data.
**Tier**: Now · **Status**: 🔴 PLANNED · **Automation**: 🤖
**Blocks**: W07 adoption visibility · **Unblocks**: confidence during W09 per-page migrations. Dashboard is most useful starting when STEP 3 (primitive build) ships and the 5 W09 migrations begin.

## Why this exists

Today the adoption state of every primitive lives in 4 separate places (claude.ai/design · `/design-lab/handoffs` · `/design-lab/overlays` · `DESIGN_CATALOG.md`), and the "which pages are using this primitive?" answer requires `grep -r "from '@/components/primitives/"`. Zero live cross-reference.

As W07 builds primitives and W09 migrates pages to use them, the adoption counts currently drift from reality because DESIGN_CATALOG.md is hand-maintained. A live-scan manifest + sibling tab to [Modules](W11.02_MODULES_DASHBOARD_TAB.md) closes the loop.

## Scope

**In**:
- `scripts/build-primitives-manifest.ts` — scans `src/components/primitives/**/*.tsx` + greps all `src/**/*.{ts,tsx}` for `from '@/components/primitives/` imports + checks latest snapshot under `docs/99-refactor/_system/design/handoffs/` for "designed" status. Writes `docs/99-refactor/_system/PRIMITIVES_MANIFEST.json`.
- Vite dev-middleware at `/api/primitives-manifest` serves the manifest (same pattern as `/docs-assets/handoffs-index`)
- New tab at `/refactor-dashboard` → **Primitives** (sibling to existing **Modules** tab)
- Table columns: Primitive · Group · 🎨 Designed · 💻 Built · 🚢 Adopted count · Adopters (click to expand)
- Filters: group · stage · search
- Row click → drawer: iframe latest handoff preview + live `.tsx` render side-by-side + full adopters list + last-modified timestamp + links to `/design-lab/overlays` + `/design-lab/handoffs`
- Manifest regenerated on: dev-server start · Husky pre-commit (optional · opt-in) · `npm run build`

**Out**:
- No mutation UI — dashboard is read-only. Promotions still happen via `/design-import --promote`.
- No auto-DESIGN_CATALOG-sync. Dashboard becomes the source of truth for adoption; DESIGN_CATALOG Adopted column can reference it or be deprecated later.
- No production bundle — route is dev-only.

- **Consumes**: [W11 Refactor dashboard](W11_REFACTOR_DASHBOARD.md) shell · [W23 Handoff staging](W23_DESIGN_LAB_HANDOFF_STAGING.md) snapshot folder convention · `src/components/primitives/CONTEXT.md` inventory
- **Updates as data arrives from**: W07 Phase 2 (primitive build → 💻 Built flips 🟢) · W09 migrations (page adopts → Adopters list grows)
