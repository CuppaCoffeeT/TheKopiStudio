Typography

Two fonts only. Load from Google Fonts.

Instrument Serif — Headings Only
Elegant, distinctive serif. Use for h1, h2, h3, page titles. Never smaller than 18px. Weights: 400 regular.
@import url('https://fonts.googleapis.com/css2?family=Instrument+Serif:ital@0;1&display=swap');
IBM Plex Sans — Body & UI
Clean, readable sans. Use for all body text, buttons, labels. Weights: 400, 500, 600, 700.
@import url('https://fonts.googleapis.com/css2?family=IBM+Plex+Sans:wght@400;500;600;700&display=swap');

Where Each Colour Goes

Brown (#8b6a47)
Page headers, primary buttons, section titles (with Instrument Serif), active navigation, hover states. The "authority" colour.
Text Dark (#3a2e24)
All body copy, form labels, important text. Default text colour throughout.
Sage (#5a7a5e)
Secondary buttons, accent lines, success states, links. Complements brown without competing.
Muted (#7d6b5b)
Subtitles, helper text, disabled states, secondary information. Lower visual weight.
Page Background (#f0e6d6)
Body/page background. Warm cream tone.
Cards/Boxes (#faf6ee)
All content boxes, cards, sections. Lighter cream than page bg for subtle lift.

Quick CSS Variables

Paste this into your root CSS for consistency:

:root {
  --color-primary: #8b6a47;
  --color-secondary: #5a7a5e;
  --color-background: #f0e6d6;
  --color-card: #faf6ee;
  --color-text-dark: #3a2e24;
  --color-text-muted: #7d6b5b;
  --color-border: #d9ccc0;
  --color-positive: #5a7a5e;
  --color-negative: #d97551;
  --font-heading: 'Instrument Serif', serif;
  --font-body: 'IBM Plex Sans', sans-serif;
}
For your developer: Website uses Primary Palette only (Brown, Cream, Sage, Text). Reports layer in Extended Palette (Grey, Green, Red sentiment). Keep it consistent — same brown (#8b6a47) and cream (#faf6ee) across website and reports so clients recognize "this is The Kopi Studio."
